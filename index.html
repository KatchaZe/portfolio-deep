📖 How to — วิธีอ่านแดชบอร์ดนี้ (ตามหลัก Damodaran)

หลักคิดรวม: Value ก่อนเสมอ (ราคาเทียบมูลค่า) → คุณภาพ (moat + งบไว้ใจได้) → จังหวะ (momentum เป็นแค่ตัวจับเวลาเข้า ไม่ใช่เหตุผลซื้อ) — ตัวเลขทุกตัวมี tooltip เมื่อเอาเมาส์ชี้

1) Card ของหุ้นแต่ละตัว

ส่วนแสดงอะไรอ่าน/ตีความอย่างไร
จุดสี หน้า tickerConfidence tier ของข้อมูล (เขียว/เหลือง/แดง)แดง = ข้อมูลขาดหลายช่อง อย่าเพิ่งเชื่อ Fair Value มาก · ⚑ = จำนวน data flags (ชี้ดูรายละเอียด)
คะแนน DEEP + ดาวคะแนนรวม 0–5 จาก D-E-E-P (ถ่วงน้ำหนัก D 20% / E_exec 20% / E_econ 30% / P 30%)≥4 = BUY, 3–4 = HOLD/Accumulate, 2–3 = HOLD, <2 = SELL/AVOID — เทียบ "ระหว่างหุ้น" ได้เพราะ rubric เดียวกัน

GARP badgeคะแนน ถูก×ดี (Economics + Price, /10)candidate = ทั้งสองด้าน ≥3 (Damodaran S13/S19: growth at a reasonable price)
MomentumComposite 4 เงื่อนไข: 12-1 >0 · 6M >0 · เหนือ SMA200 · RSI>50Strong/Positive = จังหวะหนุน · ⚠ crash guard = ตลาด RISK-OFF ห้ามไล่ราคา (S9) · ⏳ = ข้อมูลเก่า กด Run Daily
Rankอันดับ momentum 12-1 เทียบหุ้นตัวอื่นในพอร์ต/ลิสต์ (percentile)Top = แข็งสุดในกลุ่ม — ใช้เลือก "ตัวไหนก่อน" เมื่อ value ใกล้กัน
Actionสรุปคำสั่งรายวัน = สัญญาณ value ผสมสัญญาณ momentumBUY/ACCUMULATE เมื่อทั้งคู่หนุน · WAIT/WATCH เมื่อขัดกัน · TRIM/SELL เมื่อแพงและ momentum เสีย
Anchor FVFair Value ต่อหุ้นจาก "ทุกวิธีที่คำนวณได้" — ★ คือวิธีหลักที่ใช้คิด UpsideFVP = Future Value Projection (หุ้นโตแรง moat กว้าง: spread>10pp และ growth>15%) · PEG = Fundamental PEG (กรณีทั่วไป) · RevDCF = หุ้นยังไม่มีกำไร แสดงเป็น %CAGR ที่ตลาด price-in แทนราคาเป้า
Upside(FV−ราคา)/ราคา + net หลังภาษี/ค่าเทรด (S6)>+15% = มี margin of safety · <−15% = จ่ายแพงกว่ามูลค่า · หุ้น pre-profit: เทียบ actual %/y กับ implied — actual ≥ implied = ทำได้ตามที่ตลาดคาด
Earnings · EPS/Rev/Mgn · 5qผล 5 ไตรมาสล่าสุด (เก่า→ใหม่): EPS และ Revenue = beat/meet/miss เทียบ estimate นักวิเคราะห์ · Mgn = แนวโน้ม operating margin YoY (expand/flat/contract)เขียวต่อเนื่อง = execution ดี · แดงซ้ำ = ประมาณการโลกสวย/ธุรกิจแผ่ว · ชี้จุดสีดู Act vs Est · "× n/a" = ดึงไม่ได้ทั้งแหล่งหลักและสำรอง · "⟳ refresh" = ข้อมูลชุดเก่า กด Run Fundamental Refresh · PEAD = ทิศ drift หลังงบ (S25)
Verdict + 💡สรุป 1 บรรทัด + คำแนะนำ action สังเคราะห์จากทุกค่าบน cardเรียงตาม มูลค่า → คุณภาพ → จังหวะ → Action — ใช้เป็นข้อสรุปเร็ว แล้วกดดู drawer (WACC/Ke/EVA + sub-scores) เพื่อ audit ที่มา

แถบแสดงอะไร / ตีความ
Market regime (S9)S&P เหนือ/ใต้ 200-DMA — RISK-ON = สัญญาณ momentum เชื่อถือได้ขึ้น · RISK-OFF = momentum crash-prone อย่าไล่ราคา
Market valuation (S32/33)implied ERP เทียบ earnings-yield และ Fed spread — CHEAP/FAIR/EXPENSIVE เป็น "ตัวเอียงน้ำหนัก" ไม่ใช่สัญญาณเข้า-ออกตลาด

Philosophy fit (S1/S42)พอร์ตที่ถือ "กำลังเล่นแนวไหน" (value/quality/momentum) ตรงกับ profile ที่ตั้งไว้ไหม — ถ้าไม่ตรง แปลว่า drift โดยไม่รู้ตัว

3) หน้า Allocation — หัวข้อ 1–7

หัวข้อแสดงอะไรเกณฑ์ / ตีความ (Damodaran)
GARP screenจัดอันดับทุกตัว = Quality (Economics) × Cheap (Price)candidate = ≥3 ทั้งคู่ — รายชื่อที่ควรดูก่อนเมื่อจะเพิ่มเงิน (S13/S19)
1 · Portfolio Snapshotมูลค่าพอร์ต, จำนวนตัว, Est. Vol (annual), Severe drawdown, β, Diversification /100Vol ~15–20% = โซนหุ้นล้วน · Severe drawdown คือ "ถ้าเกิด GFC ซ้ำ" — เทียบกับ Max loss ที่ตั้งไว้ · β>1.3 = แรงกว่าตลาดมาก · Diversification ≥60 ดี, <40 = กระจุก
2 · Capital Allocationโดนัทแบ่งเงินตาม "ตัวขับความเสี่ยง" (sleeve) และสกุลเงินsleeve เดียว ≥40% หรือสกุลเงินเดียว ≥80% = ความเสี่ยงกระจุกที่มองไม่เห็นจากรายตัว
3 · Capital vs Risk Weightเทียบ %เงินที่ลง (เทา) กับ %ความเสี่ยงที่สร้าง (แดง) ต่อหุ้นแดงยาวกว่าเทามาก (+3pp ขึ้นไป) = ตัวนั้น "กินความเสี่ยง" เกินเงินที่ลง — เป้าหมายแรกเวลาลดความเสี่ยง · แท่งเขียว = ช่วยลดความเสี่ยงรวม (diversifier)
4 · Concentration MapHHI, Effective N, Top-5/Top-10, ENB + สัดส่วน sectorEffective N = "ถือจริงกี่ตัว" (6 ตัวแต่ Eff N 4.2 = กระจุก) · HHI >0.18 = เข้มข้น · ENB = จำนวน "เดิมพันอิสระ" ยิ่งน้อยยิ่งกระจุก
5 · Stress Testขาดทุนโดยประมาณถ้า scenario ประวัติศาสตร์/สมมุติเกิดซ้ำ + VaR/CVaR[JUDG-SCENARIO] = ภาพประกอบไม่ใช่พยากรณ์ · ใช้ตอบคำถามเดียว: "เลวร้ายสุดรับได้ไหม" — ถ้าไม่ได้ ให้ลดขนาด ไม่ใช่หวังว่าจะไม่เกิด
5b · Downside Risk (S2/S4)Vol รวม, Downside deviation, Sortino, Downside βแยก "ผันผวน" จาก "เสี่ยงขาลงจริง" — Sortino >1 ดี · downside β >1 = วันตลาดลง เราลงแรงกว่า
6 · Suitabilityเทียบ drawdown ที่ผูกพัน กับ Max loss ที่บอกว่ารับได้⛔ = พอร์ตเสี่ยงเกินใจรับ — FINDING สำคัญสุดของหน้านี้ แก้ด้วยการลดขนาด/เพิ่ม ballast (bond/cash/gold)
7 · Rebalancing Planรายการ TRIM/ADD จาก % ปัจจุบัน → เป้าหมาย + vol ก่อน/หลังMust = เกิน policy band ต้องทำ · Should = ควรทำ — ขายผู้ชนะบางส่วนเข้าตัวที่ยังถูกคือวินัย ไม่ใช่การทำนายตลาด
What-ifลองใส่เงินซื้อเพิ่ม แล้วดูสัดส่วนพอร์ต "หลังซื้อ"ใช้เช็คก่อนซื้อจริงว่าเงินใหม่ทำให้กระจุกขึ้นหรือกระจายขึ้น

ลำดับใช้งานที่แนะนำ: เปิด Allocation ดูข้อ 6 ก่อน (รับได้ไหม) → ข้อ 3/4 (อะไรคือตัวกินความเสี่ยง) → ข้อ 7 (ต้องทำอะไร) → ค่อยกลับไป My Portfolio ตัดสินใจรายตัวด้วย card

📚 Ref — นิยามค่าที่คำนวณ (Damodaran-based)

อัตราคิดลด & ต้นทุนเงินทุน

ค่านิยามเกณฑ์ / เทียบกับอะไร
RfRisk-free rate = yield พันธบัตรสหรัฐ 10 ปี (ดึงสด ณ วัน refresh)ฐานของทุกอย่าง — Rf ขึ้น → FV ทุกตัวลดลงโดยกลไก
ERPEquity Risk Premium (implied, US) — ผลตอบแทนส่วนเพิ่มที่ตลาดหุ้นต้องจ่ายเหนือ Rfตั้งมือ (config) — แอปจะ flag เมื่อเก่ากว่า 3 เดือน · ERP สูง = ตลาดกลัว = หุ้นถูกลงทั้งกระดาน
Beta (β)ความไวของหุ้นต่อตลาดใช้ใน Ke — β>1 ผันผวนกว่าตลาด · ของพอร์ต = ถ่วงน้ำหนักรายตัว
KeCost of equity = Rf + β×ERP — ผลตอบแทนขั้นต่ำที่ "ผู้ถือหุ้น" ควรได้ใช้คิดลดกระแสเงินสดของผู้ถือหุ้น (FCFE) และเป็นเพดานเทียบ growth
Kd a-tCost of debt หลังภาษี = (Rf + default spread)×(1−tax) — spread ประเมินจาก interest coverageถูกกว่า Ke เสมอ (เจ้าหนี้เสี่ยงน้อยกว่า) · "a-t" = after-tax เพราะดอกเบี้ยหักภาษีได้
WACCต้นทุนเงินทุนถ่วงน้ำหนัก = Ke×(E/V) + Kd a-t×(D/V)ไม้บรรทัดวัด ROIC — บริษัท "สร้างมูลค่า" ก็ต่อเมื่อ ROIC > WACC

คุณภาพธุรกิจ

ค่านิยามเกณฑ์
ROIC*NOPAT / Invested Capital — * คือปรับ R&D เป็นสินทรัพย์ (capitalize อายุ 5 ปี) ตามวิธี Damodaran เพื่อไม่ลงโทษบริษัทที่ลงทุนอนาคตผ่าน R&Dเทียบ WACC เท่านั้น (ตัวเลขเดี่ยว ๆ ไม่มีความหมาย)
SpreadROIC − WACC = ส่วนเกินมูลค่าที่สร้างต่อเงินลงทุน 1 หน่วย≥+10pp = moat แข็งแรง · 0 ถึง +10pp = ปกติ · ติดลบ = ทำลายมูลค่า (โตแค่ไหนก็ไม่ช่วย)
EVAEconomic Value Added = Spread × Invested Capital ($ ต่อปี)แปลง spread เป็น "เม็ดเงินมูลค่าที่สร้างจริงต่อปี" — โตพร้อม EVA บวก = โตแบบมีคุณค่า
Incremental ROICΔNOPAT / เงินลงทุนใหม่ปีล่าสุดบอกว่า "เงินก้อนใหม่" ยังได้ผลตอบแทนดีไหม — ดีกว่าดู ROIC เฉลี่ยอย่างเดียว
Earnings quality (EQ)3 เช็ค: cash conversion (CFO/NI), accruals/assets, SBC/revenueCLEAN = ผ่านหมด · REVIEW = ติด 1–2 ข้อ · LOW = กำไรบนกระดาษ อย่าใช้ EPS ตรง ๆ · SBC คิดผ่าน dilution ไม่หักคะแนนซ้ำ (no double counting)

มูลค่า (Fair Value methods)

ค่านิยามใช้เมื่อไร
Fundamental PEGFair P/E จากโมเดล 2-stage (growth, ROIC, Ke) × forward EPS — ไม่ใช่ PEG ตลาดที่ใช้ค่าคงที่ 1.0วิธีหลักกรณีทั่วไป (หุ้นมีกำไร โตปกติ)
FVPFuture Value Projection: EPS โต 5 ปี × exit P/E (คุมเพดาน 12–25x) คิดลดกลับด้วย Keวิธีหลักเมื่อ moat กว้าง (spread>10pp) และโตแรง (>15%) — เพราะ PEG จะกดหุ้นคุณภาพสูงเกินจริง
RevDCF (implied CAGR)Reverse DCF: ราคาปัจจุบัน → ตลาดกำลัง price-in การเติบโตรายได้กี่ %/ปี 10 ปี (terminal margin ยึดจาก op margin จริง)หุ้นยังไม่มีกำไร — เทียบ implied กับ actual: Plausible (<1.5× ของที่ทำได้) / Ambitious / Aggressive / Exceptional (>5× = priced for perfection)
Anchor FV / ★วิธีที่ methodology verdict เลือกเป็นหลักในการคิด Upsidecard แสดงทุกวิธีเสมอ — ถ้าสองวิธีต่างกันมาก แปลว่ามูลค่า "sensitive ต่อสมมติฐาน" ให้ลดความมั่นใจ
Upside / net(FV−P)/P · net = หลังหักภาษี capital gains ~15% + ค่าเทรด ~0.2% (S6)ตัดสินใจด้วย net เสมอ — S6: ต้นทุน/ภาษีคือเหตุผลใหญ่ที่ active แพ้ index
EPS×n badgeforward EPS ใช้ค่า blend จาก n แหล่ง (Yahoo/FMP/Finnhub) + ช่วง min–maxspread ระหว่างแหล่ง >25% = ประมาณการไม่นิ่ง ลดความเชื่อมั่น FV

คะแนน DEEP & สัญญาณ

ค่านิยามเกณฑ์
D — Demandการเติบโตรายได้ + ปรับ organic (หัก M&A), เทียบ median กลุ่ม, durability จาก consensus fade0–5 · ≥25% โต = ฐาน 4–5
E — Executionฐานจาก EQ + แนวโน้ม margin + incremental ROIC0–5 · ทีมบริหารแปลงโอกาสเป็นกำไรได้จริงไหม
E — Economicsฐานจาก Spread + แนวโน้ม spread 5 ปี0–5 · หัวใจของ moat — น้ำหนักมากสุดร่วมกับ P (30%)
P — Pricemargin of safety เทียบ Anchor FV + ตำแหน่ง P/E ตัวเองใน 5 ปี0–5 · MOS ≥+40% = 5 · ต่ำกว่า −40% = 1
GARP /10Economics + Price รวมกันcandidate เมื่อ ≥3 ทั้งคู่ (ถูก×ดี, S13/S19)
Momentum 12-1ผลตอบแทน 12 เดือนโดย "ข้ามเดือนล่าสุด" (มาตรฐานงานวิจัย เลี่ยง short-term reversal)ใช้จัด Rank Top/Mid/Bottom ระหว่างตัวที่ถือ
S9 crash guardตลาดใต้ 200-DMA = momentum เสี่ยง crashveto สัญญาณ bullish ชั่วคราว — ไม่ใช่สัญญาณขายพื้นฐาน
PEAD (S25)Post-Earnings Announcement Drift — ราคามีแนวโน้มไหลตามทิศ surprise ล่าสุดต่ออีกระยะ▲/▼ + * = แรง · ใช้ประกอบจังหวะ ไม่ใช่เหตุผลหลัก

ความเสี่ยงพอร์ต (หน้า Allocation)

ค่านิยามเกณฑ์
HHIผลรวมกำลังสองของน้ำหนัก (0–1)<0.10 กระจายดี · >0.18 เข้มข้น · 1.0 = ตัวเดียว
Effective N1/HHI = จำนวนหุ้น "ที่ถือจริงเชิงเศรษฐกิจ"เทียบจำนวนตัวจริง — ห่างมาก = กระจุก
ENB (risk)Effective Number of Bets — จำนวนเดิมพันอิสระเมื่อคิด correlation แล้วต่ำกว่า Effective N เสมอ · ยิ่งใกล้ 1 = ทั้งพอร์ตคือเดิมพันเดียว
DR (normal/crisis)Diversification Ratio = ค่าเฉลี่ยถ่วง vol รายตัว / vol พอร์ตใกล้ 1 = การกระจายแทบไม่ช่วย · crisis DR สำคัญกว่า เพราะ correlation วิ่งเข้า 1 ตอนวิกฤต
%Risk weightสัดส่วน risk contribution จาก covariance (ไม่ใช่สัดส่วนเงิน)ต่างจาก %Capital มาก = ความเสี่ยงซ่อน — ดูหัวข้อ 3
VaR 95/99ขาดทุนสูงสุดที่ "ไม่น่าจะเกิน" ใน horizon ที่เลือก ด้วยความเชื่อมั่น 95/99%CVaR = ค่าเฉลี่ย "เมื่อทะลุ VaR แล้ว" — สะท้อน tail จริงกว่า
Downside dev / Sortino / Downside β (S2/S4)วัดเฉพาะฝั่งขาลง: ส่วนเบี่ยงเบนขาลง · ผลตอบแทนต่อความเสี่ยงขาลง · ความไวเฉพาะวันตลาดลบSortino >1 ดี · downside β >1 = ตกแรงกว่าตลาด
Suitabilitydrawdown ที่ผูกพัน (แย่สุดจาก stress/VaR) เทียบ Max loss ที่ผู้ใช้รับได้เกิน = FINDING หลัก ต้องแก้ที่ "ขนาด" ก่อนเสมอ
