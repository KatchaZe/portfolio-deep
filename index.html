2ราคา + P/Lราคาล่าสุด + %เปลี่ยน และกำไร/ขาดทุนของ position (มุมขวา ตัวจาง)ตั้งใจให้เป็น "บริบท" ไม่ใช่พระเอก — มูลค่า (เกจ #3) ต้องมาก่อนราคาเสมอ (S5) · Watchlist ไม่มี P/L แต่มีปุ่ม + Portfolio
3เกจ Price vs Valueขีดดำ = ราคาปัจจุบันบนสเกล FV (เขียว = โซน margin of safety / เทา = fair ±15% / แดง = แพง) + FV และวิธีที่ใช้คำถามแรกของ Damodaran ตอบใน 1 วินาที · หุ้น pre-profit แสดงเป็น 2 แท่ง implied vs actual แทน (Reverse DCF) · bond/gold/crypto ไม่มีเกจ เพราะเป็นเกม pricing (S40-41)
4Upside gross → net(FV−ราคา)/ราคา แล้วหักค่าเทรด ~0.2% + ภาษี capital gains ~15%ตัดสินใจด้วย net เสมอ (S6) — ต้นทุน/ภาษีคือเหตุผลใหญ่ที่ active แพ้ index
5คะแนน DEEP + ดาวคะแนนรวม 0–5 จาก D-E-E-P (ถ่วงน้ำหนัก D 20% / E_exec 20% / E_econ 30% / P 30%)≥4 = BUY, 3–4 = HOLD/Accumulate, 2–3 = HOLD, <2 = SELL/AVOID — เทียบ "ระหว่างหุ้น" ได้เพราะ rubric เดียวกัน
6Moat / EQ / GARP badgesMoat = ROIC−WACC spread (pp) · EQ = earnings quality CLEAN/REVIEW/LOW · GARP = ถูก×ดี (Economics + Price, /10)Moat ≥+10pp = แข็งแรง, ติดลบ = ทำลายมูลค่า · EQ วัดว่ากำไรกลายเป็นเงินสดจริงไหม (cash conversion ≥0.8, accruals ≤5% ของ assets, SBC ≤10% ของรายได้) · GARP candidate = ทั้งสองด้าน ≥3 (S13/S19)
7Momentum / Rank / ActionMomentum = composite 4 เงื่อนไข (12-1 >0 · 6M >0 · เหนือ SMA200 · RSI>50) · Rank = percentile 12-1 เทียบตัวอื่นในพอร์ต/ลิสต์ · Action = value × momentumStrong/Positive = จังหวะหนุน · ⏳ = ข้อมูลเก่า กด Run Daily · Rank Top = ใช้เลือก "ตัวไหนก่อน" เมื่อ value ใกล้กัน · Action: BUY/ACCUMULATE เมื่อทั้งคู่หนุน · WAIT/WATCH เมื่อขัดกัน · TRIM/SELL เมื่อแพงและ momentum เสีย · ตลาด RISK-OFF จะแสดง WAIT · crash guard ทับสัญญาณฝั่งซื้อชั่วคราว (S9)
8Anchor FVFair Value ต่อหุ้นจาก "ทุกวิธีที่คำนวณได้" — ★ คือวิธีหลักที่ใช้คิด Upside · EPS×n = forward EPS blend จาก n แหล่งFVP = Future Value Projection (หุ้นโตแรง moat กว้าง: spread>10pp และ growth>15%) · PEG = Fundamental PEG (กรณีทั่วไป) · RevDCF = หุ้นยังไม่มีกำไร แสดงเป็น %CAGR ที่ตลาด price-in แทนราคาเป้า · สองวิธีต่างกันมาก = FV sensitive ต่อสมมติฐาน ลดความมั่นใจ
9ช่อง Upsideตัวเลข upside + net ซ้ำในตาราง grid · หุ้น pre-profit: actual %/y เทียบ implied CAGR>+15% = มี margin of safety · <−15% = จ่ายแพงกว่ามูลค่า · pre-profit: actual ≥ implied = ทำได้ตามที่ตลาดคาด
10S9 guard badgesแถบเตือนแดง = crash guard (ตลาดใต้ 200-DMA) · แถบเหลือง = reversal (วิ่งสะสม ~3 ปี ≥+150% และใกล้ยอด)แสดงเฉพาะเมื่อเกิดจริง — เป็น "veto จังหวะเข้า" ชั่วคราว ไม่ใช่สัญญาณขายพื้นฐาน (S9: momentum พังแรงสุดตอนตลาดกลับทิศ / 3–5 ปี = โซน mean reversion)
11Earnings · EPS/Rev/Mgn · 5qผล 5 ไตรมาสล่าสุด (เก่า→ใหม่): EPS และ Revenue = beat/meet/miss เทียบ estimate นักวิเคราะห์ · Mgn = แนวโน้ม operating margin YoY (expand/flat/contract) · PEAD = ทิศ drift หลังงบ (S25)เขียวต่อเนื่อง = execution ดี · แดงซ้ำ = ประมาณการโลกสวย/ธุรกิจแผ่ว · ชี้จุดสีดู Act vs Est · "× n/a" = ดึงไม่ได้ทั้งแหล่งหลักและสำรอง · "⟳ refresh" = ข้อมูลชุดเก่า กด Run Fundamental Refresh
12Verdict + 💡 adviceสรุป 1 บรรทัด + คำแนะนำ action สังเคราะห์จากทุกค่าบน cardเรียงตาม มูลค่า → คุณภาพ → จังหวะ → Action ตามลำดับ Damodaran — momentum ไม่มีวัน override value
13Drawerกดกางดู WACC / Ke / Kd / ROIC* / Spread / EVA + sub-score breakdown (audit trail)ทุกคะแนนตรวจย้อนได้ว่ามาจากตัวเลขไหน — ฐาน + adjustment ทีละรายการ (เขียว = บวก, แดง = ลบ, เทา = ข้ามเพราะไม่มีข้อมูล)
–Card แบบ bond/gold/cryptoถ้า ticker อยู่ใน asset-class map (TLT, GLD, BTC-USD, …) card จะไม่แสดง FV/GARP/EQ แต่ติดป้าย BOND · rate risk (S3) หรือ PRICING ASSET (S40-41)สินทรัพย์ไม่มีกระแสเงินสด ตีมูลค่าไม่ได้ ได้แต่ตีราคา — จำกัดน้ำหนัก อย่าปนกับส่วน valuation · bond ดูผลอัตราดอกเบี้ยที่ Allocation → Bond rate risk
